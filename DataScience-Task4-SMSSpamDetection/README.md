# SMS Spam Detection using Machine Learning

## Objective
To develop a machine learning-based system that classifies SMS messages as spam or legitimate (ham).

## Technologies Used
- Python
- Google Colab
- Pandas
- Scikit-learn
- Matplotlib
- Seaborn
- Natural Language Processing (NLP)
- TF-IDF

## Dataset
SMS Spam Collection Dataset.

## Machine Learning Algorithms
1. Multinomial Naive Bayes
2. Logistic Regression

## Project Workflow
1. Dataset loading and inspection
2. Data cleaning and preprocessing
3. Text preprocessing
4. TF-IDF vectorization
5. Train-test splitting
6. Model training
7. Model evaluation
8. Confusion matrix analysis
9. WordCloud visualization
10. Testing new messages

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix

## Conclusion
This project demonstrates the use of Natural Language Processing and machine learning algorithms to classify SMS messages into spam and ham categories.
