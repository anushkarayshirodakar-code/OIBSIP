# Sales Prediction Using Python

## About the Project
This project uses Machine Learning regression techniques to predict product sales based on advertising expenditure across TV, Radio and Newspaper channels.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## Dataset
Advertising.csv

## Models Implemented
1. Linear Regression
2. Random Forest Regression

## Evaluation Metrics
- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- R² Score

## Project Workflow
- Data Collection
- Data Cleaning
- Exploratory Data Analysis
- Data Visualization
- Model Training
- Model Evaluation
- Feature Importance Analysis

## Results
The models were compared using regression evaluation metrics to identify the better-performing model.

## Conclusion
The project demonstrates how machine learning can be used to analyse advertising expenditure and predict product sales.
